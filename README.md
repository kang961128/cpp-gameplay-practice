# C++ Console Combat Simulator

C++ 기본 문법과 객체지향 설계를 학습하며 제작한 콘솔 기반 전투 시뮬레이터입니다.

캐릭터의 상태와 행동을 클래스로 설계하고, 기본 공격·스킬·쿨다운을 이용한 턴제 전투를 구현했습니다. 주요 규칙은 테스트 모드를 통해 자동으로 검증할 수 있습니다.

## 주요 기능

* 캐릭터별 ID, 이름, HP, 최대 HP, 공격력 관리
* 피해, 회복, 사망, 부활 처리
* 캐릭터별 고유 스킬과 피해량
* 스킬 사용 및 턴 기반 쿨다운
* `std::vector`를 이용한 파티 관리
* ID를 이용한 캐릭터 검색
* 공격자와 대상 선택
* 잘못된 입력과 존재하지 않는 ID 처리
* 기본 공격과 스킬을 이용한 자동 턴제 전투
* 승자와 진행 턴 수를 담은 `BattleResult`
* 게임 실행 및 테스트 실행 모드
* `assert`를 이용한 주요 기능 검증

## 전투 규칙

* 스킬을 사용할 수 있으면 스킬을 우선 사용합니다.
* 스킬이 쿨다운 중이면 기본 공격을 사용합니다.
* 기본 공격을 사용한 턴에는 남은 스킬 쿨다운이 1 감소합니다.
* HP가 0이 된 캐릭터는 공격하거나 회복할 수 없습니다.
* 대상이 사망하면 반격하지 않고 전투가 종료됩니다.

### 파일별 역할

* `Character`: 캐릭터의 상태와 행동 관리
* `Skill`: 스킬 피해량, 사용 가능 여부 및 쿨다운 관리
* `Battle`: 턴 진행, 행동 결정 및 전투 결과 계산
* `CharacterSearch`: ID를 이용한 캐릭터 검색
* `CharacterTests`: 캐릭터와 검색 기능 테스트
* `SkillTests`: 스킬과 쿨다운 테스트
* `BattleTests`: 전투 결과와 스킬 재사용 테스트
* `NexonCppStudy`: 사용자 입력과 프로그램 실행 흐름 관리

## 테스트 항목

테스트 모드에서 다음 동작을 검증합니다.

* 잘못된 최대 HP와 공격력 보정
* 일반·초과·음수·0 피해 처리
* 일반·초과 회복과 사망 상태의 회복 제한
* 캐릭터 사망과 부활
* 생존·사망 캐릭터의 공격
* 캐릭터 고유 공격력 적용
* 존재하거나 존재하지 않는 ID 검색
* 스킬 피해량과 쿨다운 초기화
* 쿨다운 중 스킬 재사용 차단
* 쿨다운 감소 후 스킬 재사용
* 전투 턴 수, 최종 HP 및 승자 계산

## 실행 방법

1. Visual Studio에서 `NexonCppStudy.slnx`를 엽니다.
2. 솔루션을 빌드합니다.
3. `Ctrl + F5`로 프로그램을 실행합니다.
4. 실행 모드를 선택합니다.

```text
1. Run game
2. Run tests
```

### 게임 모드

캐릭터 목록을 확인한 뒤 공격자와 대상을 ID로 선택합니다.

### 테스트 모드

캐릭터, 검색, 스킬, 전투 테스트를 실행하고 결과를 출력합니다.

## 현재 한계와 개선 가능 항목

* 캐릭터마다 하나의 스킬만 보유
* 사용자가 전투 행동을 직접 선택하지 않고 자동으로 진행
* 콘솔 환경에서 한 번의 전투만 진행
* `assert` 기반 테스트는 Release 설정에서 비활성화될 수 있음
* 향후 전용 테스트 프레임워크를 도입할 수 있음

## 개발 방식

기능을 작은 단위로 구현하고 빌드와 테스트를 반복하며 개선했습니다. 클래스별 책임을 나누고 헤더와 구현 파일을 분리해 코드 구조를 정리했습니다.

AI는 C++ 개념 학습, 설계 검토 및 오류 원인 분석에 활용했습니다. 제안된 코드는 직접 작성하고 실행 결과와 테스트를 통해 동작을 확인했습니다.
