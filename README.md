# C++ Console Combat Simulator

C++ 기본 문법과 객체지향 설계를 학습하며 제작한 콘솔 기반 전투 시뮬레이터입니다.
캐릭터의 상태와 전투 규칙을 구현하고, 사용자 입력과 테스트를 통해 동작을 검증합니다.

## 주요 기능

* `Character` 클래스를 이용한 캐릭터 상태 관리
* 피해, 회복, 사망, 부활 처리
* 최대 HP를 벗어나지 않도록 상태값 제한
* `std::vector`를 이용한 여러 캐릭터 관리
* ID를 이용한 캐릭터 검색
* 사용자 입력을 통한 공격자와 대상 선택
* 잘못된 숫자 및 존재하지 않는 ID 입력 처리
* 턴 단위 전투 진행과 결과 출력
* `assert`를 이용한 주요 기능 테스트

## 프로젝트 구조

```text
cpp-gameplay-practice/
├── README.md
├── NexonCppStudy.slnx
└── NexonCppStudy/
    ├── Character.h
    ├── Character.cpp
    └── NexonCppStudy.cpp
```

* `Character.h`: `Character` 클래스 선언
* `Character.cpp`: 캐릭터 기능 구현
* `NexonCppStudy.cpp`: 전투 진행, 사용자 입력, 캐릭터 검색 및 테스트

## 적용한 C++ 개념

* 클래스와 접근 제어
* 생성자와 멤버 초기화 목록
* 캡슐화와 Getter
* 참조와 포인터
* `const` 멤버 함수와 const reference
* `std::vector`와 범위 기반 `for`문
* 헤더 파일과 구현 파일 분리
* 입력 스트림 오류 처리
* `assert`를 이용한 동작 검증

## 테스트 항목

현재 다음 동작을 확인하는 테스트를 포함합니다.

* 잘못된 최대 HP 보정
* 일반·초과·음수·0 피해 처리
* 일반·초과 회복 및 사망 상태의 회복 제한
* 캐릭터 부활
* 생존·사망 캐릭터의 공격
* 존재하는 ID 검색
* 존재하지 않는 ID 검색

## 실행 방법

1. Visual Studio에서 `NexonCppStudy.slnx`를 엽니다.
2. 프로젝트를 빌드합니다.
3. `Ctrl + F5`로 실행합니다.
4. 공격자 ID, 대상 ID, 공격력을 차례대로 입력합니다.

## 현재 한계와 개선 계획

* 테스트 코드와 실행 코드를 별도의 파일로 분리
* 전투 진행 기능을 별도의 클래스로 분리
* 캐릭터별 공격력과 스킬 구현
* 전투 로그 및 추가 예외 처리
* 표준 테스트 프레임워크 도입
